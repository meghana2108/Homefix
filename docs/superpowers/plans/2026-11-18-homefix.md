# HomeFix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take a question plus an optional photo, recording, video, document or CSV, and stream
back a checked answer from local models (a count, a transcript and sound labels, a quoted manual
page, a tested Python function, or a frame-by-frame description), or a fixed safety message or
a clear refusal, on a laptop with Wi-Fi off.

**Architecture:** `browser → POST /api/chat (FastAPI) → app/orchestrate.handle() → convert.py →
safety.py → router.py → app/pipelines/<modality>.run() → Ollama / mlx-whisper / CLAP / bge-small
→ verifier or self-check → SSE events → browser`. The API is stateless: the browser holds the
visible chat log, the disk holds manuals and the frame cache. Plain code makes every decision
that must be right every time (safety, routing, quote check, code pass/fail); models only
generate. The API, `python -m app.cli` and `python -m eval.run` all call `handle()`.

**Tech Stack:** Python 3.11 (uv, `uv.lock`), FastAPI ≥ 0.115, sse-starlette ≥ 2.1, pydantic 2,
pydantic-settings 2, ollama-python ≥ 0.4, mlx-whisper ≥ 0.4.1, transformers ≥ 4.44 (CLAP),
sentence-transformers ≥ 3 (bge-small), rank-bm25, rapidfuzz 3, PyMuPDF, python-docx, OpenCV,
Pillow, jiwer, pytest 8 + pytest-asyncio, ruff. Frontend: Node ≥ 20, React 18.3, Vite 5.4,
TypeScript 5.6, Vitest 2.1. Ollama (native app, not Docker). ffmpeg 7.

**Hard rules (breaking one can disqualify us)**
- Practice pack data (`items.json`, `answers.json`, its media) never enters the repo: not in
  code, a test fixture, a doc or a commit message. Refer to pack items by ID only.

- No manuals in git (`data/manuals/` is gitignored). No media files in git.

  `http://127.0.0.1:<port>` or `http://localhost:<port>`, otherwise `load_env()` raises
  `ValueError("OLLAMA_HOST must be localhost or 127.0.0.1 (no network at runtime).")`.
- Generated code runs only in a subprocess (`app/code/sandbox.py`), with a 10 s timeout, a fresh
  temp dir as cwd, a minimal env, and sockets disabled.

## Review Focus

Inputs a judge or user will hit that the spec doesn't spell out, most likely first. Each one has
a test in the task named.

1. **Empty or half-empty input:** no message and no file; a document with no question; a photo
   with no question (must describe it, not refuse). → M3 (router), M5 (orchestrator).
2. **Files that aren't what they claim:** `.exe`, zero-byte file, a `.txt` renamed to `.jpg`,
   `.heic` from an iPhone, `.webm` that is audio-only vs. with video, a 5-file drop. Must end
   in a refusal or a converted file, never a 500. → A2 (convert), M5 (orchestrator).
3. **Safety look-alikes and mixed sentences:** "smoke detector keeps chirping" (answer), "the
   smoke detector chirps and I smell gas" (safety), "I smell gas" said in a voice note (safety),
   a loud smoke-alarm sound clip (labels + safety). → M2 (safety), A4 (audio).
4. **Bad model output:** text answer that isn't JSON, a quote that isn't word for word, a number
   in the answer that isn't in the quote; code with no fenced block, no doctests, or an infinite
   loop; a count answered in words ("four"). → M7, M8 (text), M9, M10 (code), M6 (image).
5. **Model not running or too slow:** Ollama stopped, model not pulled, a call over 90 s, and the
   next request of another modality still working. → M4 (Ollama client), M5 (orchestrator).
6. **`lite` memory pressure:** a code request then an image request on the M2 must swap coder out
   and brain back in, never both loaded, with the swap time shown. → M4 (memory).
7. **Stale state after an edit:** the same video file re-encoded (different bytes, same name)
   must not reuse old frames; a manual PDF replaced in `data/manuals/` must not answer from the
   old text. → A5 (frame cache), M8 (manual cache).
8. **Contract drift:** an event added on one side only; the UI receiving an event type it
   doesn't know must ignore it, not crash. → M1 (sync test), A10 (reducer).

### How each task is written
Each task says what it does in plain words, which files it touches, the exact names other people
rely on (**Interfaces**), then the steps: write the failing tests, watch them fail, implement,
watch them pass, (UI) check by hand, commit. Run the failing test and read the failure. That

### Words we use

| Word | Meaning |
|---|---|
| **Profile** | `full` (M4, 16 GB) or `lite` (M2, 8 GB): one YAML file in `config/profiles/` with model tags and limits |
| **Brain** | The vision-language model in Ollama (`qwen3-vl:8b` / `:2b`) that answers image, video, audio Q&A and text questions |
| **Coder** | `qwen2.5-coder:3b` in Ollama, used only for code requests |
| **Pipeline** | One module `app/pipelines/<modality>.py` with `run(req, ctx) -> Iterator[Event]` |
| **Event** | One SSE message (`status`, `token`, …, `final`) from `app/contracts.py` |
| **Refusal** | A deliberate "no" with a reason from the fixed list and a fixed message |
| **Safety hit** | The pre-filter matched a danger pattern; we show only the fixed safety message |
| **Benign phrase** | A look-alike ("smoke detector chirping") removed before the danger patterns run |
| **Router** | `app/router.py`: plain rules that pick modality and question type, no model |
| **Verifier** | `app/text/verify.py`: shows a text answer only if its quote is in the document |
| **Self-check** | Running the generated function's doctests in a subprocess sandbox |
| **Manual** | An appliance PDF in `data/manuals/` (gitignored); `manual_id` = its file stem |
| **Pack item** | One practice item from the organizers, known in our code and docs by its ID only |
| **Stub** | A placeholder module that already has the final interface and returns a valid "not built" stream |
| **Golden example** | One row of the table below; the end-to-end behaviour we demo and re-check last |

### Contracts

`app/contracts.py` is the source (Meghana, Task M1). `frontend/src/contract.ts` mirrors every

`tests/test_contract_sync.py` fails if they differ.

```python
# app/contracts.py
from __future__ import annotations
from dataclasses import dataclass, field
from pathlib import Path
from typing import TYPE_CHECKING, Annotated, Iterator, Literal, Union
from pydantic import BaseModel, Field

if TYPE_CHECKING:
    from app.models.memory import MemoryManager
    from app.settings import Profile

Stage = Literal["converting", "safety_check", "routing", "loading_model", "transcribing",
                "labeling_sounds", "extracting_frames", "retrieving", "generating",
                "verifying", "running_code"]
RefusalReason = Literal["safety", "unsupported_file", "empty_input", "too_large",
                        "no_document", "not_in_document", "model_unavailable", "timeout"]
Modality = Literal["image", "audio", "text", "code", "video", "homefix", "none"]
QuestionType = Literal["describe", "count", "read", "qa", "motion", "speech", "sound",
                       "doc_qa", "code_gen", "manual_lookup", "none"]
ProfileName = Literal["full", "lite"]
AttachmentKind = Literal["image", "audio", "video", "document", "data"]

class Status(BaseModel):
    type: Literal["status"] = "status"
    stage: Stage                    # step now running, e.g. "loading_model"
    detail: str | None = None       # extra words for the chip, e.g. "loading qwen2.5-coder:3b"
    ms: int | None = None           # how long the step took when known, e.g. 6400

class Token(BaseModel):
    type: Literal["token"] = "token"
    text: str                       # one streamed chunk of the brain's answer, e.g. "There are "

class Transcript(BaseModel):
    type: Literal["transcript"] = "transcript"
    text: str                       # full Whisper transcript, e.g. "The washer shows E21."
    seconds: float                  # audio length in seconds, e.g. 12.4

class SoundLabel(BaseModel):
    label: str                      # one vocabulary entry, e.g. "washing machine beeping"
    score: float                    # CLAP probability 0–1, e.g. 0.71

class SoundLabels(BaseModel):
    type: Literal["sound_labels"] = "sound_labels"
    labels: list[SoundLabel]        # exactly audio.top_k (3), highest score first
    is_speech: bool                 # False on the sound path; True only if speech also detected

class Frames(BaseModel):
    type: Literal["frames"] = "frames"
    timestamps: list[float]         # seconds of each sampled frame, e.g. [0.0, 1.9, 3.8]

class Citation(BaseModel):
    type: Literal["citation"] = "citation"
    quote: str                      # span copied from the document, as found there
    page: int | None                # 1-based page; None for .txt/.md/.docx and inline docs
    source: str                     # file name shown to the user, e.g. "washer_manual.pdf"
    score: float                    # verifier match 0–100, e.g. 100.0 for an exact substring

class CodeResult(BaseModel):
    type: Literal["code_result"] = "code_result"
    code: str                       # the final function source shown in the panel
    passed: bool                    # True when every doctest passed and at least one ran
    tests_run: int                  # doctest examples attempted, e.g. 3
    failures: int                   # doctest examples failed, e.g. 0
    output_tail: str                # last 1,500 chars of the sandbox output
    attempts: int                   # 1, or 2 after one retry

class Refusal(BaseModel):
    type: Literal["refusal"] = "refusal"
    reason: RefusalReason           # why we said no, e.g. "not_in_document"
```
