| D11 | 2026-11-19 | Lite brain is `qwen3-vl:2b-instruct`, not `qwen3-vl:2b` | `qwen3-vl:2b` is the thinking build and ignores `think=False` when an image is attached: one video question produced 4,264 hidden tokens and took 247 s. | D12 | 2026-11-19 | Video sends frames tiled 2×2 into grids, a motion direction measured in code (`app/video/motion.py`), and one whole middle frame for counts | Each image costs qwen3-vl about 1,050 tokens at any size, so 8 separate frames overflow lite's 8,192-token context. | D13 | 2026-11-19 | Every Ollama call uses `ctx.memory.num_ctx(role)` and `ctx.memory.keep_alive(role)` | Ollama reloads a model whenever `num_ctx` changes, which adds seconds to the next request |
| D14 | 2026-11-19 | Full brain is `qwen3-vl:8b-instruct`, not `qwen3-vl:8b` | `ollama show qwen3-vl:8b` lists "thinking" with default on, same problem as D11. The instruct tag lists no thinking; `go_no_go.py --profile full` prints GO with it |
